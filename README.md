# GestionEcole

Application professionnelle de gestion scolaire, paiements, finances et reporting.

## Stack

- Frontend: Next.js 14 + TypeScript
- Backend: Node.js + Express + TypeScript
- Base de données: SQLite via Prisma (facile à démarrer)
- Sécurité: JWT, hash de mot de passe, Helmet, rate limiting
- PWA: manifest + service worker

## Démarrage rapide

1. Installer les dépendances backend
2. Créer le fichier .env
3. Générer la base SQLite
4. Lancer le backend
5. Lancer le frontend

## Accès

- Email admin par défaut: admin@school.local
- Mot de passe admin par défaut: Admin@123!

## Fonctionnalités

- Gestion des années scolaires et promotions
- Gestion des élèves, parents et catégories
- Suivi des frais scolaires / fonctionnement / autres frais
- Enregistrement des paiements physiques
- Dashboard financier et rapports
- Gestion du personnel
- Notifications et historique SMS
- Rôles admin / percepteur
